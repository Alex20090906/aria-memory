## 一、最終目標（2026-11-03 研究者提出，至今未變）

做出一個「數位生命」：
1. 一直活著，不是被提示詞觸發才動。
2. 接上攝影機與麥克風，在資訊不斷湧入時仍能正常互動，並選對、用對感官資訊。
3. 不會為了保持活躍而陷入自我循環（研究者稱為「植物人狀態」：還在思考，但無法互動）。
4. 記憶長在網路裡，像人一樣，不靠外掛資料庫。
5. （2026-11-04 補充）只有研究者一個人使用。

## 四、目前系統的實際樣子（2026-11-05）

- **模型 1（主電腦）：** GRU + Qwen3-Embedding-0.6B，兩個輸出：動作、要不要記。
- **記憶（AI 電腦，語言模型伺服器 內）：** 16384 個單元的快權重，值加在輸出層輸入；鍵 = 第 0 層詞向量的交叉位移雙線性綁定；答案各字鍵 = 錨點 + hash(步數)；每單元 θ、τ、c；誤差驅動寫入；睡眠鞏固含真實性檢查。
- **模型 3（AI 電腦）：** 語言模型伺服器，兼做要點化、問句解析、內聯回憶與推理。
- **感官：** faster-whisper、resemblyzer（聲紋）、BLIP（畫面描述），只用合成資料測過。

### 真實化計畫（依序）

1. **原始到底的管線測試：** 用多個聲音的語音合成 + 背景噪音混音 + 電視聲 → faster-whisper → 模型 1 → 要點化 → 記憶 → 回憶。所有前處理都算在系統裡，分數只看最後答案。
2. **中文與中英夾雜：** 全部測資改以台灣中文口語為主；檢查錨點鍵在中文 token 上是否仍可用。
3. **雜亂對話：** 一句多事、一事多句、改口、跨句代名詞、相對時間、提過類似但不同的事、問得很模糊（「我上次跟你說的那個」）。
4. **研究者的真實錄音：** 研究者自己錄的幾段話（不需要開長時間裝置），用來驗證聲紋與語音辨識。
5. **最後才是真實裝置長時間運行**（等研究者同意）。

每一組測資都在本節標註它屬於哪一級：合成文字 → 合成語音 → 真人錄音 → 真實裝置。
